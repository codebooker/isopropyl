A FEW THINGS TO KNOW

Before you write.

Will it erase my USB drive?+

Yes. Writing bootable media replaces the selected drive’s contents. Back up anything you need and check the drive’s name and capacity before confirming.

Can I create a Windows installer on a Mac?+

Yes—the Apple silicon preview creates UEFI/FAT32 media from supported Windows installer ISOs, splitting large install.wim files when needed. It preserves the installer’s x64 or ARM64 boot files. Legacy BIOS support is not included in this preview path.

Are all features available on every platform?+

No. Linux has the broadest set of tools. macOS and Windows focus on image writing and installer preparation. New Windows workflows still need real-device testing; preview builds may contain bugs.

Is ISOpropyl free?+

Yes. ISOpropyl is open-source software licensed under AGPL-3.0-or-later. There are no subscriptions or account requirements. Windows installation media does not include a Windows license.
